# Mirror AI · Visual identity

**Warm light. A thoughtful face. Space for a question.**

A visual reference for the Mirror AI GitHub showcase.

[GitHub showcase](https://github.com/Mirror-Corporation) · [Manifesto](https://github.com/Mirror-Corporation/manifesto) · [mirror-ai.app](https://mirror-ai.app)

## Name and message

Use **Mirror AI** in prose and **MIRROR AI** as a display label.

Lead with an invitation to conversation. Explain the experience plainly: historical personalities as AI reconstructions, real-time voice, free letters, and memory of past conversations. State that characters speak Russian and can make mistakes.

| :--- | :--- | :--- |
| Mint | `#3FE0C8` | Action accents and small details. |
| Ochre | `#C99A5C` | Warm accents beside the artwork. |
| Charcoal | `#111719` | Dark surfaces. |
| Warm ivory | `#F4F0E8` | Light surfaces and text on dark backgrounds. |

Check text contrast in the actual context. Keep captions as live text so they follow the reader's theme.

## Type

| Use | Typeface |
| :--- | :--- |
| Headings, body, names and interface | **Geist** |
| Dates, labels and technical notation | **Geist Mono** |

GitHub controls the font used to render a README. Use its native headings, links and tables; do not turn the copy into images to imitate a custom font.

## Artwork

Use original Mirror portraits and rooms: painterly historical settings, warm light and dark surroundings. Give the paintings room to breathe.

- Identify portraits as AI reconstructions.
- Put names, historical lifespans and conversation topics in live text.
- Keep banners free of embedded text.
- Compress each published bitmap to WebP or PNG, within the showcase asset limit.
- Use artwork that remains legible beside both GitHub themes.

## Words

Prefer concrete invitations: **Bring a question. Explore a perspective. Continue a conversation.**

Describe what is available. Keep historical fact separate from generated dialogue. Use **AI reconstruction** consistently; avoid claims of resurrection, an authentic historical recording, or human identity.
